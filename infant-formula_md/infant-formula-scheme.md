# 婴幼儿配方乳粉营养素连续打分方案

## 1. 方案概述 📌

本方案依据 **GB 10765-2021** 中 33 项营养素的最小值、最大值，对实测值 `kjhl` 进行连续评分。

设计目标：

- 保留“中间高、边界低、超范围重扣”的评分思路；
- 不使用 20%、80% 硬分圈，避免边界跳变；
- 单项得分连续，范围 `0～100`；
- 支持不同营养素权重；
- 支持 `N.S.`（无上限）项目；
- 最终输出加权总分。

---

## 2. 符号定义 🔤

| 符号 | 含义 |
|---|---|
| `L` | 最小值 |
| `U` | 最大值 |
| `x` | 实测值 `kjhl` |
| `W` | 区间宽，`W = U - L` |
| `t` | 归一化位置，`t = (x - L) / W` |
| `base` | 边界基础分，默认 `60` |
| `p` | 区间内曲线形状参数，默认 `2` |
| `k` | 超范围下降速度，默认 `8` |
| `m` | 无上限项目接近满分速度，默认 `2` |

---

## 3. 单项评分规则 🧮

### 3.1 有上下限项目

适用于 `U` 存在且 `U > L` 的项目。

#### 3.1.1 实测值在区间内

条件：

```text
L ≤ x ≤ U
```

计算：

```text
W = U - L
t = (x - L) / W
score = base + (100 - base) × [1 - (2 × |t - 0.5|)^p]
```

默认参数：

```text
base = 60
p = 2
```

得分特点：

| 位置 | `t` | 得分 |
|---|---|---|
| 区间中心 | `0.5` | `100` |
| 区间边界 | `0` 或 `1` | `60` |
| 越靠近中心 | — | 得分越高 |
| 越靠近边界 | — | 得分越低 |
| 变化方式 | — | 连续，无跳变 |

#### 3.1.2 实测值低于下限

条件：

```text
x < L
```

计算：

```text
W = U - L
d = (L - x) / W
score = max(0, base × exp(-k × d))
```

默认参数：

```text
base = 60
k = 8
```

#### 3.1.3 实测值高于上限

条件：

```text
x > U
```

计算：

```text
W = U - L
d = (x - U) / W
score = max(0, base × exp(-k × d))
```

默认参数：

```text
base = 60
k = 8
```

---

### 3.2 无上限项目

适用于 `U = None` 或 `N.S.` 的项目，例如 α-亚麻酸。

#### 3.2.1 实测值低于下限

条件：

```text
x < L
```

计算：

```text
d = (L - x) / L
score = max(0, base × exp(-k × d))
```

默认参数：

```text
base = 60
k = 8
```

#### 3.2.2 实测值不低于下限

条件：

```text
x ≥ L
```

计算：

```text
score = base + (100 - base) × [1 - exp(-m × (x - L) / L)]
```

默认参数：

```text
base = 60
m = 2
```

得分特点：

- 刚好等于下限时，得分 `60`；
- 高于下限后，得分逐渐接近 `100`；
- 不会因为无限高而无限加分。

## 5. 单项得分与加权得分 📊

### 5.1 单项得分

单项得分是每个营养素根据实测值，用连续打分函数算出的原始分数。

范围：

```text
0 ～ 100
```

它回答：

> 这个营养素本身表现得好不好？

### 5.2 加权得分

加权得分是在单项得分基础上，乘以该营养素的权重。

公式：

```text
加权得分 = 单项得分 × 权重
```

它回答：

> 这个营养素对最终总分的实际贡献有多大？

### 5.3 区别

| 对比项 | 单项得分 | 加权得分 |
|---|---|---|
| 含义 | 这一项自己得了多少分 | 这一项对总分贡献了多少 |
| 公式 | `score` | `score × weight` |
| 范围 | 0～100 | 例如 0～300 |
| 是否考虑权重 | 不考虑 | 考虑 |
| 用途 | 看单项好坏 | 算总分 |
| 是否最终结果 | 不是 | 也不是，还要除以权重总和 |

---

## 6. 总分计算 🧾

单项得分记为 `score_i`，权重记为 `weight_i`。

最终总分：

```text
总分 = Σ(score_i × weight_i) / Σ(weight_i)
```

说明：

- 总分范围 `0～100`；
- 权重越高的营养素，对总分影响越大；
- 避免简单平均导致重要营养素被稀释。

---

## 7. 33 项以外营养素处理 ➕

33 项以外营养素作为附加分处理。

规则建议：

- 每项根据含量合理性给 `0～1` 分；
- 附加分总分封顶，例如最多 `+5` 分；
- 不建议“有就加分”，而应“合理才加分”；
- 防止为了评分而堆料。

示例：

```text
bonus = min(5, Σ(extra_score_j))
```

最终总分可表示为：

```text
最终总分 = 基础加权总分 + bonus
```

如果希望总分不超过 100，可以：

```text
最终总分 = min(100, 基础加权总分 + bonus)
```

## 9. 参数默认值 ⚙️

| 参数 | 默认值 | 作用 |
|---|---|---|
| `base` | `60` | 边界基础分 |
| `p` | `2` | 区间内曲线形状 |
| `k` | `8` | 超范围下降速度 |
| `m` | `2` | 无上限项目接近满分速度 |

参数调整建议：

| 目标 | 调整 |
|---|---|
| 边界更严格 | 降低 `base`，提高 `k` |
| 中间更宽松 | 提高 `p` |
| 超范围扣得更狠 | 提高 `k` |
| 无上限项目更快接近满分 | 提高 `m` |

## 10. 计算流程图 🗺️

```text
输入：L、U、x
  │
  ├─ U 存在吗？
  │   │
  │   ├─ 是
  │   │   ├─ L ≤ x ≤ U ？
  │   │   │   ├─ 是：t = (x-L)/W
  │   │   │   │      score = base + (100-base)×[1-(2×|t-0.5|)^p]
  │   │   │   └─ 否：d = 超出比例
  │   │   │          score = base × exp(-k×d)
  │   │   │
  │   └─ 否（N.S.）
  │       ├─ x < L ：d = (L-x)/L
  │       │          score = base × exp(-k×d)
  │       └─ x ≥ L ：score = base + (100-base)×[1-exp(-m×(x-L)/L)]
  │
  └─ 输出：score，范围 0～100
```

## 11. Python 参考实现 🐍

```python
import math


def score_normal(x, L, U, base=60.0, p=2.0, k=8.0):
    """
    有上下限的营养素连续打分。
    x: 实测值
    L: 最小值
    U: 最大值
    base: 边界基础分
    p: 区间内曲线形状参数
    k: 超范围下降速度
    返回 0~100 的分数
    """
    if U is None or U <= L:
        raise ValueError("U 必须大于 L")

    W = U - L

    if L <= x <= U:
        t = (x - L) / W
        score = base + (100 - base) * (1 - (2 * abs(t - 0.5)) ** p)
        return max(0.0, min(100.0, score))
    else:
        if x < L:
            d = (L - x) / W
        else:
            d = (x - U) / W
        score = base * math.exp(-k * d)
        return max(0.0, min(100.0, score))


def score_no_upper(x, L, base=60.0, k=8.0, m=2.0):
    """
    只有下限、没有上限的营养素连续打分。
    x: 实测值
    L: 最小值
    base: 下限处基础分
    k: 低于下限时下降速度
    m: 高于下限时接近满分的速度
    """
    if x < L:
        d = (L - x) / L
        score = base * math.exp(-k * d)
        return max(0.0, min(100.0, score))
    else:
        score = base + (100 - base) * (1 - math.exp(-m * (x - L) / L))
        return max(0.0, min(100.0, score))


def score_one(x, L, U):
    """
    根据实测值、上下限，返回单项得分。
    """
    if U is None:
        return score_no_upper(x, L)
    else:
        return score_normal(x, L, U)
```

## 12. 一句话总结 ✅

> 按 GB 10765-2021 的 33 项营养素，用连续函数打分：区间内以中心最高、边界 60 分，公式为 `base + (100-base)×[1-(2×|t-0.5|)^p]`；超范围用 `base×exp(-k×d)` 快速下降；无上限项目单独处理；单项 `0～100` 分，按权重加权汇总为总分。
