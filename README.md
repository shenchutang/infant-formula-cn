## 📌 特别说明

- 使用 AI 完成大部分代码编写
- **不保证**数据完整性、一致性和有效性
- 产品名称为申报名称，可能与大众熟知名牌有差异
- 未考虑**豆基**配方产品
- 红色方块也可能是由于**申报数据**缺失造成
- 2021年前的产品因**国标标准**提高无参考价值
- 方案以**国标标准**占据主导，导致结果差异较大，纯属数据比较，仅供娱乐
- 计算方式不同也导致结果差异较大，例如**附加分**上限的设定不同
- 打分不构成任何价值判断及购买建议
- 结合性价比更容易选择适合的配方乳粉产品
- 请注意配方乳粉产品国外版本和国内版本可能不同
